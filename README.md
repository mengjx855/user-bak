# This repository backup some key useful file.

- win11/UserDefinedPhrase_emoji.dat: the user defined phrase (emoji) for daily works.
- win11/UserDefined.YoudaoNote.bulb.min.js: the user defined youdao note style. modified font-size, font-color, font-face of words in quote function. When in use, need to remove the prefix `UserDefined.YoudaoNote.`, and put this file in `C:\Users\[username]\AppData\Local\youdao\Ynote\[version]\bulbeditor\`.
- win11/bulb.min.js: the default youdao note style file.
